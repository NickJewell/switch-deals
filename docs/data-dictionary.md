## Endpoints
- Catalogue (Solr): `https://searching.nintendo-europe.com/en/select` (`q=*&fq=type:GAME`, page with `start`/`rows`; **`rows=1000` is accepted**; stable paging needs `sort=fs_id asc`).
- Prices: `https://api.ec.nintendo.com/v1/price?country=GB&lang=en&ids=…` (≤50 ids).

## Headline findings
- `type:GAME` docs: **23,869**. On sale (`price_has_discount_b:true`): **2,791**.
- **`/en/` index prices are GBP.** Price API currencies: {'GBP': 50}. For 50 most-downloaded single-nsuid on-sale titles: regular price matches 50/50, sale price matches 49/50, 1 index-says-sale-but-API-doesn't (index lags). → **Price API is the only source for spoken/on-screen prices.**
- API `raw_value` is a string without trailing zeros (`"7.2"`) — parse with Decimal into integer pence.
- **Price fields:** `price_regular_f`, `price_discounted_f`, `price_discount_percentage_f`, `price_lowest_f`, `price_sorting_f`. `price_lowest_f` null rate on sale docs: 0/2791.
- **There is no lowest-ever price field.** `price_lowest_f` == `price_sorting_f` on 2791/2791 on-sale docs; it equals the discounted price on single-nsuid docs and the *regular* price on docs not on sale. It is the cheapest **current** price across the doc's nsuids. → ATL must come from our own snapshot history (or an external history source).
- **Index price fields can mix nsuids.** e.g. FINAL FANTASY VII REBIRTH carries `70010000112478` (GB £49.99→£7.49) and `70070000032076` (£64.99→£9.74); the doc shows regular 64.99 / discounted 9.74 / lowest 7.49. Treat them as hints only.
- **`nsuid_txt` is a list.** Count per on-sale doc: {0: 8, 1: 2706, 2: 59, 3: 17, 4: 1}. Prefixes: {'7001': 2665, '7007': 194, '7005': 20}. When a doc has one nsuid, its prefix: {'7001': 2588, '7007': 118}.
  - `7001…` = base game application, `7007…` = bundle / edition (e.g. complete editions, multi-game bundles), `7005…` = add-on (only seen alongside others). Primary nsuid rule: lowest `7001…`, else lowest id.
  - 8 on-sale docs have no nsuid at all → cannot be priced; skipped.
- **No `popularity` field exists.** `hits_i` is constant ({300: 2791}) → useless. Use **`downloads_rank_i`: lower = more popular, 999999 = unranked.** Ranked on-sale docs: 1845/2791. Top by rank: FINAL FANTASY VII REBIRTH (28), Hogwarts Legacy (37), FINAL FANTASY VII REMAKE INTERGRADE (39), Grand Theft Auto: The Trilogy – The Definitive Edition (40), Hogwarts Legacy (54), Red Dead Redemption (94), LEGO® Marvel™ Super Heroes (115), LEGO® Star Wars™: The Skywalker Saga (138).
